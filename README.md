# ComfyUI-MyDemoPlugin

> 一个用于图像处理的 ComfyUI 自定义节点插件，提供亮度调整、颜色反转和随机种子生成功能。

------

## 📦 安装方法

### 方式一：手动安装（推荐）

1. 下载本仓库，将文件夹放入 ComfyUI 的 `custom_nodes` 目录：

```
ComfyUI/
└── custom_nodes/
    └── ComfyUI-MyDemoPlugin/   ← 放这里
        ├── __init__.py
        ├── README.md
        └── nodes/
            ├── __init__.py
            └── image_nodes.py
```

1. 重启 ComfyUI，终端出现以下输出即表示安装成功：

```
✅ [MyDemoPlugin] 节点加载成功！
```

### 方式二：Git 克隆

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/RiverAndTao/ComfyUI-MyDemoPlugin.git
```

## 🧩 节点说明

在 ComfyUI 画布中右键 → 搜索框输入节点名称，或在菜单 **`MyDemoPlugin`** 分类下找到所有节点。

------

### 🎨 图像亮度调整（ImageBrightnessNode）

> 分类路径：`MyDemoPlugin / 图像处理`

对输入图像进行亮度和对比度的调整。

**调整公式：**

```
output = (input - 0.5) × contrast + 0.5 + brightness
```

#### 输入参数

| 参数名       | 类型   | 默认值      | 范围         | 说明                                         |
| ------------ | ------ | ----------- | ------------ | -------------------------------------------- |
| `image`      | IMAGE  | —           | —            | 输入图像（必填）                             |
| `brightness` | FLOAT  | `0.0`       | `-1.0 ~ 1.0` | 亮度偏移，正值变亮，负值变暗                 |
| `contrast`   | FLOAT  | `1.0`       | `0.0 ~ 3.0`  | 对比度系数，小于1降低对比度，大于1增强对比度 |
| `label`      | STRING | `processed` | —            | 输出标签，用于标识本次处理（可选）           |

#### 输出

| 输出名       | 类型   | 说明                                                         |
| ------------ | ------ | ------------------------------------------------------------ |
| `处理后图像` | IMAGE  | 调整后的图像                                                 |
| `标签信息`   | STRING | 包含参数值的描述字符串，如 `processed | brightness=0.20, contrast=1.50` |

#### 使用示例

```
亮度 +0.2、对比度 1.5 → 画面更明亮且层次更分明
亮度 -0.3、对比度 0.8 → 画面偏暗且柔和
亮度  0.0、对比度 1.0 → 原图不变
```

### 🔄 图像颜色反转（ImageInvertNode）

> 分类路径：`MyDemoPlugin / 图像处理`

对图像进行颜色反转，产生负片效果。

**调整公式：**

```
output = 1.0 - input
```

#### 输入参数

| 参数名           | 类型    | 默认值 | 范围    | 说明                                      |
| ---------------- | ------- | ------ | ------- | ----------------------------------------- |
| `image`          | IMAGE   | —      | —       | 输入图像（必填）                          |
| `channels`       | INT     | `3`    | `1 ~ 3` | 反转的通道数：1=仅R，2=RG，3=全部RGB      |
| `preserve_alpha` | BOOLEAN | `True` | —       | 是否保留 Alpha 通道（如果图像含透明通道） |

#### 输出

| 输出名     | 类型  | 说明             |
| ---------- | ----- | ---------------- |
| `反转图像` | IMAGE | 颜色反转后的图像 |

#### 使用示例

```
channels=3 → 全通道反转，经典负片效果
channels=1 → 只反转红色通道，产生偏色效果
channels=2 → 反转红色和绿色通道
```

------

### 🎲 随机种子生成（RandomSeedNode）

> 分类路径：`MyDemoPlugin / 工具`

每次运行工作流时自动生成一个新的随机整数种子，常用于连接 KSampler 等需要种子的节点。

#### 输入参数

| 参数名      | 类型 | 默认值       | 范围      | 说明                     |
| ----------- | ---- | ------------ | --------- | ------------------------ |
| `max_value` | INT  | `4294967296` | `1 ~ 2³²` | 随机种子的最大值（不含） |

#### 输出

| 输出名     | 类型 | 说明                         |
| ---------- | ---- | ---------------------------- |
| `随机种子` | INT  | 每次运行都会生成不同的随机数 |

> ⚠️ **注意**：该节点使用了 `IS_CHANGED` 机制，每次运行都会强制重新执行，不会被 ComfyUI 缓存跳过。

## 🔗 典型工作流示例

```
[Load Image] ──→ [图像亮度调整] ──→ [图像颜色反转] ──→ [Preview Image]
                      ↑
              brightness=0.2
               contrast=1.3

[随机种子] ──→ [KSampler seed 输入]
```
